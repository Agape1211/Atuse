# Security Policy

## Supported versions

The project currently supports the latest version on the `main` branch and the most recent release tag.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately by emailing the maintainer or using the repository's private security reporting method if configured.

Include:

- a summary of the issue
- steps to reproduce it
- affected version(s)
- impact and severity assessment
- any proof of concept or suggested fix

We aim to acknowledge valid reports within 5 business days and provide a remediation plan as quickly as possible.

## Disclosure policy

We ask that reporters give us a reasonable opportunity to fix the issue before public disclosure.
